### GitHub Repository vs. Public Website

* **GitHub repository:** Where the HTML/code is stored and edited.
* **`index.html`:** The main webpage file. GitHub Pages automatically loads this file as the homepage.
* **Public website:** The actual webpage visitors can open and use.

### Publishing

This site is hosted using **GitHub Pages**.

GitHub Pages settings:

**Repository → Settings → Pages**

* Source: `Deploy from a branch`
* Branch: `main`
* Folder: `/(root)`

When changes are committed to `index.html` on the `main` branch, GitHub Pages will deploy the updated website.
